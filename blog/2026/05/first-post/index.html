1. Markdown#

Markdown 是一种轻量级标记语言，用简单的纯文本语法就能快速排版出结构清晰的内容，比如标题、列表、链接、图片、引用和代码块等。它的特点是易学、易写、可读性强，即使不经过渲染，原始文本也比较清晰，因此被广泛用于博客写作、技术文档、 README 、笔记和知识库等场景。

2. Astro#

Astro 是一个现代化的静态网站框架，主打高性能、低 JavaScript 负载和内容优先的开发方式，特别适合构建博客、文档站、作品集和营销页面。它默认采用 “按需加载” 的思路，尽可能将页面生成为静态 HTML ，只在需要交互的部分引入 JavaScript ，因此能带来更快的加载速度和更好的用户体验；同时它也支持与 React 、 Vue 、 Svelte 等前端组件生态配合使用，兼顾静态站点的简洁性和现代前端开发的灵活性。

3. MDX#

MDX 可以理解为 Markdown + JSX 的结合格式，它既保留了 Markdown 适合写文章、文档和笔记的简洁语法，又允许在内容中直接嵌入前端组件，使文档不仅能展示纯文本和基础排版，还能插入交互式图表、提示框、自定义卡片等更丰富的页面元素。因此， MDX 特别适合用在技术博客、文档站和内容型网站中，让 “写内容” 和 “写组件” 能够自然地融合在一起。
